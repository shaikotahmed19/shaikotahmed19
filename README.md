## 👨‍💻 About Me

I'm **Shaikot Ahmed**, a frontend developer and WordPress specialist with experience building responsive websites, user interfaces, themes and practical developer tools. I've worked on frontend and WordPress projects since **2016**, including remote development and client-facing support for **Webalive Australia**.

- 🧩 **Frontend:** JavaScript, React, Vue.js, responsive UI development and component-based workflows.
- 🌐 **WordPress:** theme development, Elementor, PHP customization, maintenance and troubleshooting.
- 🛠️ **Approach:** clear communication, maintainable code and practical problem-solving.
- 🎯 **Focus:** growing deeper in WordPress technical support while continuing to build polished frontend experiences.
- 🤝 **Open to:** meaningful remote collaboration in frontend development and WordPress support.
